1. 공지 내용

영업담당자분들께서는 참고 부탁드립니다.
앞으로 판매, 수리, 샘플과 관련해서는 사진에서 보이는 메디퍼스트처럼 보이시겠지만, 가납창고로 납품되는 물품들은 기존과 달리 창고이동에서 불러와 생성이 되므로 경희의료원처럼 구분이 됨을 알아두시면 좋을 것 같습니다.
이로 인해 담당자인 제가 창고이동에서 제대로 생성되었는지를 더 주의깊게 확인해야 하므로, 출고 요청 시 제가 연차로 인해 없다고 해도 반드시 웍스 방에 출고 요청한다는 멘트를 남겨주시면 좋을 것 같습니다. - 곽병준 -

한 줄 요약

  • 가납창고 출고는 판매 주문서가 아니라 창고이동으로 만들어지고, 주문서조회에서는 병원 이름(예: 경희의료원)과 구분 가납창고으로 보입니다.
  • 곽병준 주임이 자리에 없어도 웍스 「재고 출고 요청」 방에 요청 글은 반드시 남깁니다.

마감월말에 그 달 실적을 병원 청구 기준에 맞춰 정리하는 주문서 (5번 참고)단가 있음병원별 지정 거래처 / "OO병원_N월 마감"대조한 기준 서류

상세 설명과 예시

  • 가납랜딩 - 새 병원이나 새 품목을 처음 세팅할 때 한 번 넣어 주는 기초 재고입니다. 이후 병원이 쓰면 사용분으로 보충합니다. (예: 두발로병원 알파벤트 랜딩 가납서)
  • 사용분 - 가납창고 재고에서 나가고 0원으로 입력합니다. 사용일은 적요에만 적고, 납품예정일·납기일자는 입력일로 둡니다. 환자별로 같은 품목이 나뉘어도 한 줄에 합산하고 적요에 "누구 몇 개"를 적습니다. (예: 청담리온, 세종스포츠, 강북삼성)
  • 선납 - 예전에는 사용분 보충도 선납으로 적었지만, 지금은 발주서 없이 급히 요청받은 납품만 선납입니다. 사용분 보충은 "사용분"으로 적습니다.
  • 판매 - 금액이 있는 주문입니다. 스마트엠(SmartM) 위탁·부서직납 발주는 SmartM에서 선납으로 표시돼도 이카운트에는 판매 주문서로 입력합니다(적요에 발주번호). 판매전표는 확인자가 처리합니다.
  • 샘플 - 0원이고, 구매로 넘어가면 기존 샘플 주문서를 고치지 않고 신규 판매 주문서를 만듭니다. 샘플 재고가 이중으로 빠지지 않는지 확인합니다. (예: 청담리온정형외과_샘플)
  • 교환 - 새 제품을 0원으로 출고하고, 불량품을 회수한 뒤 제조사 TS에 불량 접수합니다. 출고 요청은 웍스 방에 따로 올립니다. (예: 분당서울대 REELX 1개 교환, 청담리온 312 불량 교환)
  • 수리 - 병원에 견적을 먼저 보내고 승인을 받은 뒤 수리를 진행합니다. 곽 주임 「수리완료 물품 관리」 표의 "수리완료"가 해외수리 견적 대기일 수 있으므로, 병원에 안내하기 전에 TS 메일과 WO로 실제 상태를 확인합니다. (예: 고대구로 FORMULA 180 SHAVER 해외수리)

구분 고르는 순서

  1. 돈을 받는 주문인가? → 판매 (월말 정리용이면 마감)
  2. 장비 고장 수리인가? → 수리
  3. 불량품을 새 제품으로 바꿔 주는가? → 교환
  4. 구매 전 무상 평가용인가? → 샘플
  5. 가납창고에서 나가는 무상 납품이면:
    처음 세팅 → 가납랜딩 / 병원이 쓴 만큼 보충 → 사용분 / 발주서 없이 급히 요청 → 선납
주의: 진행중인 사용분 주문의 구분을 바꿀 때는 확인 후에만 하고, 이미 완료된 주문은 바꾸지 않습니다. "에이전트" 구분은 정의가 정해지기 전까지 임의로 쓰지 않습니다.

4. 가납창고 출고 요청 방법

  1. 이카운트 주문서 입력 - 거래처 가납창고(12346), 병원명 "OO병원_사용분", 구분 사용분(병원 사용분 보충) / 선납(발주서 없이 급히 요청받은 납품) / 가납랜딩(처음 세팅 납품). 사용분은 0원, 적요에 사용일·환자·수량을 적습니다.
  2. 웍스 「재고 출고 요청」 방에 요청 글 작성 - 병원, 품목, 수량, 납품 시간을 적습니다. 곽 주임 연차여도 반드시 올립니다(이번 공지의 핵심).
  3. 요청은 당일 출근 후(오전)에 올립니다. 전날 저녁에 올리지 않습니다.
  4. 같은 건을 다시 올릴 때는 수량을 합산해 새로 쓰지 말고, 이미 요청한 수량은 중복으로 적지 않습니다. 추가분만 적습니다.
  5. 출고 확인 - 주문서조회에서 진행상태가 완료로 바뀌고, 창고이동 이력이 생성됩니다.
주의: 월 사용량을 판매현황으로만 합산하면 가납창고 사용분이 빠질 수 있습니다. 가납창고 건은 주문서조회(사용분)와 창고이동 이력을 함께 보세요.

5. 월 마감 주문서 입력 방법

월 마감은 월말 기준으로 그 달 실제 납품·사용 수량을 병원 청구 기준에 맞춰 주문서로 정리하는 작업입니다.

  1. 기준 자료 확보 - 병원별 기준 서류(병원 발주 목록, SmartM 매출승인, 병원 세금계산서, 거래명세서 등)를 먼저 모읍니다. 병원별 기준은 아래 6번 표 참고.
  2. 수량 대조 - 기준 서류의 월 합계와, 이카운트 월 사용분 주문서(가납창고) 및 판매 주문서를 품목별로 맞춰 봅니다.
  3. 주문서입력 화면에서 새 주문서 작성
    일자 / 납품예정일그 달 마지막 날 (예: 11/30). 일반 주문은 입력일이지만 마감은 월말입니다.
    거래처병원별 지정 거래처(6번 표)
    담당자본인
    출하창고100 수멕스재고창고
    병원명"OO병원_N월 마감" 형식 (병원별 표기 6번 표). 병원명 칸은 Enter 이동 순서에서 건너뛰므로 직접 클릭해 입력
    구분마감 ("판매"로 입력하지 않습니다)
    분납대부분 불가
  4. 라인 입력 - 품목코드, 수량, 단가(VAT 포함). 같은 품목은 행을 늘리지 말고 한 줄에 합산합니다. 단가가 0인 줄은 공급가액·부가세에 0을 입력합니다.
  5. 저장 후 반드시 재확인 - 저장한 주문서 번호를 다시 열어 행·수량·합계가 맞는지 봅니다. 저장 시 단가가 자동으로 바뀌는 경우가 있고, 확인자가 진행중 주문서를 수정하기도 합니다.
  6. 목록 확인 - 주문서조회에서 구분 "마감", 일자 월말, 중복 주문서 없음을 확인합니다.
입력은 주문서까지가 영업 담당 업무로 정리돼 있습니다(최은성 기준). 판매전표는 확인(컨펌) 담당이 처리하므로 직접 만들지 않습니다. 담당자별 권한이 다르면 확인 후 진행하세요.

7. 마감 전 체크리스트

  • □ 일자·납품예정일이 월말인가
  • □ 구분이 "마감"인가 (판매·사용분 아님)
  • □ 병원명이 "OO병원_N월 마감" 형식인가
  • □ 기준 서류 월 합계와 마감 수량이 같은가
  • □ 같은 품목이 여러 줄로 나뉘지 않았는가
  • □ 단가·합계가 저장 후에도 맞는가
  • □ 이미 판매로 처리한 항목을 빼야 하는 병원(고대구로)인지 확인했는가
  • □ 가납창고 출고 건이 창고이동에 생성돼 완료로 바뀌었는가
  • □ 같은 마감 주문서가 이미 있지 않은가(중복 확인)

자주 하는 실수

  • 구분을 "판매"로 둔 채 저장
  • 월말이 아니라 입력일로 일자를 둠
  • 판매현황만 보고 사용량을 합산해 가납창고 사용분 누락
  • 출고 요청을 웍스 방에 남기지 않음(곽 주임 연차 시 누락 위험)
